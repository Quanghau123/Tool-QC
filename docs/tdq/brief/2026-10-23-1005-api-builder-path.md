# BRIEF — API Builder project-relative contract path
Soul: chất lượng > runtime > context cost · luật gốc: skills/tdq-conventions/references/soul.md

## Nguyên văn

Người dùng yêu cầu thay API Builder: không bắt copy OpenAPI vào `.artifacts` hay nhập absolute path; dùng đường dẫn tương đối từ project nằm trong `Tool-QC/projects/<project>/`, tự nạp từ `project.json`, portable giữa máy. Phạm vi dự kiến gồm cấu hình project, resolve path an toàn, UI và hướng dẫn; cần giữ chặn URL remote, `.env` và dữ liệu nhạy cảm.
